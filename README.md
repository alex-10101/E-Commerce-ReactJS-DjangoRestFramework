# E-Commerce Application

- Full-stack e-commerce application built with Django REST Framework and React

- Dynamic product filtering using checkboxes with URL query parameter synchronization

- Paginated product listings with server-side pagination for performance and scalability

- Multi-step forms for checkout and data collection with persisted state across steps

- Secure user authentication and authorization with account activation

- Role-based access control (RBAC) with separate user and admin permissions

- Admin product management: create, update, delete products and images

- Secure checkout and payment processing via Stripe

- Client-side state management and caching using Redux Toolkit and Redux Toolkit Query (RTK Query)

- Containerized the application using Dockerfiles and Docker Compose
